## CONTEXT

The dashboard is a custom PHP template that does not use `wp_head()` or `wp_footer()`. Extensions that need to inject a Vue mount point currently use `wp_footer`, which places their `<div>` outside the layout container — making their UI invisible. This task adds a single `do_action()` call inside `index.php`, immediately after `<div id="app"></div>` and before `</body>`, giving extensions a clean in-layout injection point.
