### `bookit-meetings/dashboard/vite.config.js` — CREATE

```js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig( {
    plugins: [ vue() ],
    base: './',
    build: {
        outDir: 'dist',
        rollupOptions: {
            output: {
                entryFileNames: 'app.js',
                assetFileNames: 'app.[ext]',
            },
        },
    },
} )
```

**`base: './'` is mandatory — never change it to `'/'`.** Using `'/'` combined with WordPress's `?v=` cache-busting query string causes two Vue instances to mount to the same DOM element (double-mount crash). This has caused bugs in core development and must never be changed.

The fixed output filenames (`app.js` / `app.css`) are intentional — they let the PHP enqueue reference predictable paths without glob scanning.

### `bookit-meetings/includes/class-bookit-meetings-assets.php` — MODIFY

Read the current file from GitHub before making any changes.

**Change 1 — Fix asset enqueue to use fixed filenames instead of glob:**

The current `enqueue_dashboard_assets()` method uses `glob()` to find hashed filenames. Now that `vite.config.js` outputs fixed filenames (`app.js` / `app.css`), replace the glob approach with direct path references:

- JS path: `BOOKIT_MEETINGS_PLUGIN_DIR . 'dashboard/dist/app.js'`
- CSS path: `BOOKIT_MEETINGS_PLUGIN_DIR . 'dashboard/dist/app.css'`
- URL construction: use `BOOKIT_MEETINGS_PLUGIN_URL` constant (read from the main plugin file to confirm the exact constant name) — do not use `plugin_dir_url()`
- Existence check: use `file_exists()` on the JS path — if the file does not exist, skip silently and log via `Bookit_Logger::warning()` (same behaviour as before, just using `file_exists()` instead of `glob()`)
- Keep the `wp_localize_script()` call exactly as-is

**Change 2 — Add mount point div output:**

Inside `enqueue_dashboard_assets()`, after the `wp_enqueue_script()` and `wp_localize_script()` calls, add:

```php
add_action( 'wp_footer', function() {
    echo '<div id="bookit-meetings-app"></div>';
} );
```

This must be inside a `wp_footer` action callback — never echo directly inside `enqueue_dashboard_assets()`.
