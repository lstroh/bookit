## API REFERENCE

### GET `bookit-meetings/v1/settings`
Returns current settings. Auth: admin session required.

Response:
```json
{
  "success": true,
  "data": {
    "meetings_enabled": "0",
    "meetings_platform": "",
    "meetings_manual_url": ""
  }
}
```

Note: `meetings_enabled` is returned as string `"0"` or `"1"` — not boolean.

### POST `bookit-meetings/v1/settings`
Updates one or more settings. Auth: admin session required.

Request body (send only keys you want to update):
```json
{
  "meetings_enabled": "1",
  "meetings_platform": "teams",
  "meetings_manual_url": "https://teams.microsoft.com/meet/abc"
}
```

Validation rules (enforced server-side):
- `meetings_enabled`: must be `"0"` or `"1"`
- `meetings_platform`: must be one of `"whatsapp"`, `"teams"`, `"generic"`, or `""`
- `meetings_manual_url`: must be a valid URL or empty string

Response: same shape as GET.

### Auth headers
All requests must include:
```js
{
  'X-WP-Nonce': window.BOOKIT_DASHBOARD.nonce,
  'Content-Type': 'application/json'
}
```

The REST base URL is `window.BOOKIT_DASHBOARD.restBase` (e.g.
`http://metting.local/wp-json/bookit/v1/`). The meetings endpoints are at
`window.BOOKIT_DASHBOARD.restBase.replace('bookit/v1/', '') + 'bookit-meetings/v1/settings'`
— or construct from `window.location.origin + '/wp-json/bookit-meetings/v1/settings'`.

### `dashboard/src/views/SettingsView.vue` — CREATE

The main settings page. Requirements:

**Layout:**
- Page heading: `"Meetings Settings"`
- A settings card/panel containing all controls
- A save button
- A status message area (success/error feedback)

**Controls (in order):**

1. **Global toggle** — uses `ToggleSwitch.vue`
   - Label: `"Enable Meetings"`
   - Description: `"Allow online meeting links to be generated for bookings"`
   - Bound to `meetings_enabled` (convert string `"0"`/`"1"` to boolean for the toggle, back to string for the API)

2. **Platform selector** — uses `PlatformSelector.vue`
   - Only visible when `meetings_enabled` is true
   - Options:
     - `whatsapp` → label `"WhatsApp"`
     - `teams` → label `"Microsoft Teams"`
     - `generic` → label `"Generic URL"`
     - `zoom` → label `"Zoom"` — **disabled, shows "Coming Soon" badge**
     - `google_meet` → label `"Google Meet"` — **disabled, shows "Coming Soon" badge**

3. **WhatsApp info panel** — only visible when platform is `"whatsapp"`
   - Info box (not an input) explaining: `"When WhatsApp is selected, no meeting link is generated. Your staff will initiate a WhatsApp call or video at the appointment time using the customer's phone number."`

4. **Manual URL field** — uses `ManualUrlField.vue`
   - Only visible when platform is `"teams"` or `"generic"`
   - Label: `"Meeting URL"`
   - Placeholder: `"https://teams.microsoft.com/meet/your-meeting-id"`
   - Bound to `meetings_manual_url`
   - Client-side validation: must be a valid URL if non-empty

**Data loading:**
- On `mounted()`, call `GET bookit-meetings/v1/settings` and populate the form
- Show a loading state while fetching
- Show an error state if the fetch fails

**Save behaviour:**
- On save button click, call `POST bookit-meetings/v1/settings` with all three keys
- Disable the save button while saving
- On success: show `"Settings saved"` message that auto-dismisses after 3 seconds
- On error: show the error message from the API response
- Do not navigate away on save

**CSS:**
- Use `var(--bookit-*)` CSS custom properties throughout — never hardcode colours
- Use `var(--bookit-color-primary)` for the toggle active state and save button
- Use `var(--bookit-bg-card)` for the settings card background
- Use `var(--bookit-border-color)` for borders
- Use `var(--bookit-text-primary)` and `var(--bookit-text-secondary)` for text
