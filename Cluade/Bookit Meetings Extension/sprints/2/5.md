## IMPLEMENTATION (only after STOP POINT is answered)

### Approach A — Filter already applied (pure Vue)

Use the same `window.fetch` intercept pattern as `BookingDetailView.vue`.

Watch for calls matching `/dashboard/my-schedule` and extract booking IDs from
the response. For each booking where a meeting indicator should show:
- `meeting_link` is non-empty (Teams/Generic), OR
- `meetings_platform` is `whatsapp` and meetings is enabled

Inject a small indicator badge into the corresponding booking card DOM element.

### `dashboard/src/views/MyScheduleView.vue` — CREATE

A new always-mounted view (like `BookingDetailView`) added to `App.vue`.

On mount:
- Intercept `window.fetch` calls matching `/dashboard/my-schedule`
- Store the list of bookings with their `meeting_link` values
- Use `MutationObserver` on `document.body` to watch for booking card elements
  appearing in the DOM
- When a card appears for a booking that has a meeting, inject a meeting
  indicator badge into the card

**Meeting indicator badge:**
- Small pill/badge element
- Icon: 📹 or a simple video camera SVG
- Text: `"Meeting"` for Teams/Generic, `"WhatsApp"` for WhatsApp platform
- Color: `var(--bookit-color-primary)` background, white text
- Must not break or overlap core card layout — append to the card, don't replace content

### `App.vue` — MODIFY

Add `MyScheduleView` as a third always-mounted component, same pattern as
`BookingDetailView`:

```vue
<template>
  <div class="bm-app">
    <RouterView />
    <BookingDetailView />
    <MyScheduleView />
  </div>
</template>
```
