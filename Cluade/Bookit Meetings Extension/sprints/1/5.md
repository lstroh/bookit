## CONTEXT

This task implements the two customer-facing output surfaces for Bookit Meetings:

1. **Confirmation page section** — injected via the `bookit_confirmation_meeting_section` filter
2. **Confirmation email section** — injected via the `bookit_email_meeting_section` filter

Both filters receive the same `$booking` array and follow the same platform logic. The output differs only in format: the confirmation page uses standard HTML with CSS classes; the email uses inline-styled, email-client-safe HTML.

Both filters are registered on a single class: `Bookit_Meetings_Customer_Surfaces`.

**Output rules per platform:**

| Platform | Confirmation page output | Email output |
|----------|--------------------------|--------------|
| `teams` or `generic` | "Join Meeting" button linking to `meeting_link` | Meeting link row with inline styles |
| `whatsapp` | "Your host will initiate a WhatsApp call/video at your appointment time." | Same text, plain paragraph with inline styles |
| Meetings disabled | Empty string — no output | Empty string — no output |
| Platform empty / unknown | Empty string — no output | Empty string — no output |
| `meeting_link` empty on teams/generic | Empty string — no output | Empty string — no output |

**Guard conditions — return `$html` unchanged (empty string) if:**
- `meetings_enabled` setting is not `'1'`
- `meetings_platform` is empty or not in `['whatsapp', 'teams', 'generic']`
- Platform is `teams` or `generic` AND `meeting_link` on the booking is null or empty

## IMPLEMENTATION REQUIREMENTS

### `bookit-meetings/includes/class-bookit-meetings-customer-surfaces.php` — CREATE

- Class name: `Bookit_Meetings_Customer_Surfaces`
- Two public filter callback methods
- One private settings reader (same `get_col()` pattern as link generator)

**`public function confirmation_page_section( string $html, array $booking ): string`**

Filter callback for `bookit_confirmation_meeting_section`. Accepts and returns
`$html` (default `''`). Returns `$html` unchanged on any guard condition.

On `whatsapp` platform, return:
```html
<div class="bookit-meeting-section bookit-meeting-whatsapp">
    <p>Your host will initiate a WhatsApp call/video at your appointment time.</p>
</div>
```

On `teams` or `generic` platform (with non-empty `meeting_link`), return:
```html
<div class="bookit-meeting-section bookit-meeting-link">
    <a href="{meeting_link}" class="bookit-meeting-btn" target="_blank" rel="noopener noreferrer">
        Join Meeting
    </a>
</div>
```

Where `{meeting_link}` is `esc_url( $booking['meeting_link'] )` and the
anchor text is wrapped in `esc_html__( 'Join Meeting', 'bookit-meetings' )`.

**`public function confirmation_email_section( string $html, array $booking ): string`**

Filter callback for `bookit_email_meeting_section`. Same guard logic.
Uses inline styles throughout — no CSS classes — for email client compatibility.

On `whatsapp` platform, return:
```html
<tr>
    <td style="padding: 12px 0; font-family: Arial, sans-serif; font-size: 14px; color: #333333;">
        Your host will initiate a WhatsApp call/video at your appointment time.
    </td>
</tr>
```

On `teams` or `generic` platform (with non-empty `meeting_link`), return:
```html
<tr>
    <td style="padding: 12px 0; font-family: Arial, sans-serif; font-size: 14px; color: #333333;">
        <strong>Meeting link:</strong>
        <a href="{meeting_link}" style="color: #4f46e5; text-decoration: none;">{meeting_link_display}</a>
    </td>
</tr>
```

Where:
- `{meeting_link}` = `esc_url( $booking['meeting_link'] )`
- `{meeting_link_display}` = `esc_html( $booking['meeting_link'] )`

**`private function get_setting( string $key, string $default = '' ): string`**

Identical to the method in `Bookit_Meetings_Link_Generator`. Copy the exact
implementation — do not call the link generator class from here.

**Important:** Both filter callbacks must read `meetings_platform` from the
settings table (not from `$booking`). The `$booking` array provides
`meeting_link` only. The platform is always read fresh from the DB on each
filter call.
