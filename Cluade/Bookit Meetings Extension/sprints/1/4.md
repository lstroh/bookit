## CONTEXT

This task implements the core business logic of Bookit Meetings: automatic
meeting link generation when a booking is confirmed. Two hooks cover the two
booking creation paths:

- `bookit_after_booking_confirmed` — public wizard bookings (fires on the
  confirmation page render, after emails are sent)
- `bookit_after_booking_created` — dashboard manual bookings (fires immediately
  after the booking row is inserted)

The logic for both hooks is identical and must be extracted into a shared
private method on the link generator class to avoid duplication.

**Platform behaviour (locked design decisions):**

| Platform | Action |
|----------|--------|
| `whatsapp` | Do nothing — no link stored. Customer is told their host will initiate the call. |
| `teams` | Copy `meetings_manual_url` to `meeting_link` on the booking row |
| `generic` | Copy `meetings_manual_url` to `meeting_link` on the booking row |
| anything else / empty | Do nothing |

**Guard conditions — do nothing if any of these are true:**
- `meetings_enabled` setting is not `'1'`
- `meetings_platform` setting is empty or not a known platform
- For `teams`/`generic`: `meetings_manual_url` is empty
- The booking row does not exist or is soft-deleted (`deleted_at IS NOT NULL`)
- `meeting_link` is already set on the booking (do not overwrite — admin
  override takes precedence)

**`public function handle_booking_confirmed( int $booking_id, array $booking ): void`**

Hook callback for `bookit_after_booking_confirmed`. Delegates to
`maybe_generate_link( $booking_id )`.

**`public function handle_booking_created( int $booking_id, array $booking_data ): void`**

Hook callback for `bookit_after_booking_created`. Delegates to
`maybe_generate_link( $booking_id )`.

Note: `$booking_data` on `bookit_after_booking_created` contains the data
array that was inserted (not a full booking row read from DB). Always re-read
the booking from `{prefix}bookings` inside `maybe_generate_link()` — never
rely on the hook parameter for current booking state.

**`private function maybe_generate_link( int $booking_id ): void`**

All guard checks and link writing happen here:

1. Read settings using `$wpdb->get_col()` — NOT `get_var()` (empty string
   safe — see Task 2 gotcha):
   ```php
   $keys = [ 'meetings_enabled', 'meetings_platform', 'meetings_manual_url' ];
   // Read each key individually using get_col() pattern from test-migrations.php
   ```

2. Guard: bail if `meetings_enabled !== '1'`

3. Guard: bail if `meetings_platform` is empty or not in
   `[ 'whatsapp', 'teams', 'generic' ]`

4. Guard: bail if platform is `whatsapp` (no link for WhatsApp — this is
   intentional, not an error)

5. Guard: bail if `meetings_manual_url` is empty (Teams/Generic require a URL)

6. Read the booking row from `{prefix}bookings`:
   ```php
   $booking = $wpdb->get_row(
       $wpdb->prepare(
           "SELECT id, meeting_link, deleted_at FROM {$wpdb->prefix}bookings WHERE id = %d LIMIT 1",
           $booking_id
       ),
       ARRAY_A
   );
   ```

7. Guard: bail if `$booking` is null (booking not found)

8. Guard: bail if `$booking['deleted_at']` is not null (soft-deleted)

9. Guard: bail if `$booking['meeting_link']` is not null and not empty
   (admin override already set — do not overwrite)

10. Write the link:
    ```php
    $wpdb->update(
        $wpdb->prefix . 'bookings',
        [ 'meeting_link' => $meetings_manual_url ],
        [ 'id' => $booking_id ],
        [ '%s' ],
        [ '%d' ]
    );
    ```

**Settings reading helper — private method:**

Extract settings reading into a private method to avoid duplication with the
API class. Do NOT import or call `Bookit_Meetings_Api` from this class —
duplicate the read logic as a private method:

```php
private function get_setting( string $key, string $default = '' ): string {
    global $wpdb;
    $results = $wpdb->get_col( // phpcs:ignore
        $wpdb->prepare(
            "SELECT setting_value FROM {$wpdb->prefix}bookings_settings WHERE setting_key = %s LIMIT 1",
            $key
        )
    );
    return empty( $results ) ? $default : (string) $results[0];
}
```
