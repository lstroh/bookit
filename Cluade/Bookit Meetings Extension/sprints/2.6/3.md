## CONTEXT

`BookingDetailView.vue` patches `window.fetch` to detect when a booking detail modal opens and renders `MeetingInfoPanel` alongside it. This works correctly — but only when `#bookit-meetings-app` is mounted. Currently the mount div is only injected on `/bookit-dashboard/app/meetings`, so the fetch intercept is never registered on other dashboard pages (bookings list, my-schedule). The fix is to inject `#bookit-meetings-app` on all dashboard pages. Vue Router continues to guard the settings UI to the `/meetings` route. `BookingDetailView` becomes always-mounted and always listening. No PHP logic changes — this is purely a scope widening of the mount point injection and a small Vue structural adjustment.
