## CONTEXT

The Bookit dashboard's `:root` block (defined in core's built CSS `style.*.css`) only defines `--bookit-primary` and `--bookit-primary-*` shade variables (e.g. `--bookit-primary-500`, `--bookit-primary-600`). It does NOT define `--bookit-bg-card`, `--bookit-border-color`, `--bookit-text-primary`, `--bookit-text-secondary`, or `--bookit-color-primary`. These variables are defined in `booking-wizard-v2.css`, which is a public-facing stylesheet never loaded on the dashboard.

As a result, all extension Vue components that reference these missing variables render invisibly (white on white, no borders). This task defines the missing variables inside `#bookit-meetings-app` so the extension is self-contained and does not depend on variables core does not provide on the dashboard.

A secondary issue: `PlatformSelector.vue` renders a `<div class="bm-platform__value">{{ opt.value }}</div>` below each platform label. This is debug output and must be removed entirely.
